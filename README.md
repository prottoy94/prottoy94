## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Rocket.png" width="32" /> Projects

**NeuroScope** · *Web app, Machine Learning*
Visualizes machine-learning models from Jupyter notebooks in interactive 3D and 2D views. It explains layers, validates shapes and parameters, simulates data flow, compares models, and supports building and exporting new models.

**Hand Gesture Controller** · *Python, OpenCV, MediaPipe*
Real-time webcam controller that detects hand landmarks and classifies gestures using configurable thresholds or a trained model. Detections are smoothed so only confirmed gestures trigger keypresses or volume changes. Includes on-screen status and per-action toggles.

**Quora Duplicate Question Detection** · *Python, NLP, Flask*
NLP pipeline that flags duplicate question pairs, with text preprocessing (contraction expansion, special-character removal). Served through a Flask web app built with the application-factory pattern and Blueprint routing.
